# GovHealth Interop — User Stories

## US-001 — Contexto unificado

**Como profissional de uma unidade de saúde,**  
quero encontrar o contexto do cidadão e do atendimento em um único fluxo,  
**para reduzir a necessidade de alternar entre sistemas.**

### Critérios

- usuário autenticado;
- contexto identificado;
- origem das informações visível;
- acesso limitado às permissões.

## US-002 — Acesso contextual

**Como profissional,**  
quero abrir um sistema externo já contextualizado no cidadão/unidade,  
**para evitar redigitação.**

## US-003 — Pendências

**Como gestor,**  
quero visualizar pendências operacionais da unidade,  
**para priorizar correções.**

## US-004 — Indicadores

**Como gestor,**  
quero indicadores por unidade/período,  
**para acompanhar operação.**

## US-005 — Auditoria

**Como administrador,**  
quero saber quem acessou ou executou determinada operação,  
**para permitir rastreabilidade.**

## US-006 — Falha de integração

**Como operador,**  
quero saber quando uma integração falhou e por quê,  
**para não confundir falha técnica com sucesso operacional.**

## US-007 — Integração

**Como equipe de TI,**  
quero adaptar o produto a diferentes sistemas sem alterar o domínio,  
**para reduzir o custo de manutenção.**
